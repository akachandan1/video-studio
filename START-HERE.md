# Start here

You don't need to know anything about video software. Claude does the editing; you describe what you want.

## 1. Install Claude Code (once)
Download the Claude desktop app (claude.ai/download) and open the **Code** tab, or install the terminal version
from claude.com/claude-code. This needs a Mac (Windows/Linux setup isn't automated yet).

> ⚠️ Uploading this folder into a normal claude.ai **chat** won't work — chat can't run the tools that render
> video. It has to be Claude **Code**.

## 2. Open this folder
In the Code tab choose **Open folder** → pick `video-studio`. (Terminal: `cd video-studio && claude`.)

## 3. Say hi
Type anything — "hi" is fine. Claude will:
1. check your Mac and list anything missing,
2. offer to install it (about 10 minutes; you approve each step),
3. render a 10-second test video to prove everything works,
4. ask what you'd like to make.

Then just describe it: *"a 30-second launch video for my app, vertical, punchy"*, *"add captions to this
video"*, *"turn this screen recording into a product demo"*.

## Good to know
- **Free by default.** Code-made shots, music, voiceover and captions cost nothing. AI-generated shots
  (Higgsfield/Fal) need your own account — Claude always tells you the cost and waits for your OK first.
- Your projects are saved in `videos/`, finished videos in `out/`. They stay on your computer.
- Something broken? Ask Claude to "run the doctor".
